# OPPO Repair Landing Page

Landing page for a smartphone repair service in Yekaterinburg.

The page has responsive desktop and mobile layouts and includes sections about the repair process, phone models, services and customer reviews.

## Tech Stack

- React
- TypeScript
- SCSS
- Redux

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The app will be available at [http://localhost:3000](http://localhost:3000).

## Note

This project focuses on the front-end layout. The forms, search and slider elements are currently visual elements and are not connected to working functionality.
