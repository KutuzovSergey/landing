# OPPO Repair Landing Page

Landing page for a smartphone repair service in Yekaterinburg.

The project includes responsive layouts for desktop and mobile screens.
The page contains information about repair services, supported phone
models, the repair process and customer reviews.

## Tech Stack

-   React
-   TypeScript
-   SCSS
-   Redux

## Getting Started

Install dependencies:

``` bash
npm install
```

Run the project locally:

``` bash
npm start
```

The app will be available at <http://localhost:3000>.

## Note

This project focuses on the front-end layout. Forms, search and slider
elements are currently not connected to working functionality.
